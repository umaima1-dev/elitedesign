# Handoffs and the weekly loop

```
Research (outlier-scout -> hook-analyst, competitor-research)
   -> Planning (content-strategist)  [founder approves plan]
   -> Studio (hook-writer -> scriptwriter / carousel-designer -> video-editor)
   -> brain-keeper check on every asset  [founder approves asset]
   -> Distribution (repurposer -> scheduler -> stories-writer, engagement-assistant)
   -> Conversion (conversion-builder)
   -> Analytics (performance-tracker -> analyst)
   -> recommendations back to Research and Planning
```

## Handoff format

Every handoff is a markdown file in the receiving department's folder with this header:

```
From: <agent>
To: <agent>
Slot: <weekly plan row>
Inputs used: <files>
Brain check: PASS | FIX | BLOCK
Open questions: <list or none>
```

## Weekly cadence

| Day | Step |
|---|---|
| Sun | Analyst report, outlier scan |
| Mon | Strategist drafts week, founder approves |
| Tue to Thu | Studio production, Brain checks |
| Daily | Scheduler queue, stories, engagement triage |
| Fri | Performance Tracker final pull for the week |
