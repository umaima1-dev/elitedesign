# Hook types

Shared vocabulary for Hook Analyst and Hook Writer.

| Type | Pattern | Example shape |
|---|---|---|
| Contrarian | Challenge a belief the audience holds | "Stop doing X. Do Y." |
| Number + outcome | Specific number tied to a result | "3 prompts that cut my admin by half" |
| Curiosity gap | Withhold the key detail | "The one setting I changed that fixed this" |
| Pain callout | Name the exact frustration | "Your AI answers sound robotic because..." |
| Story open | Drop into the middle of a moment | "Last Tuesday a client asked me..." |
| Demo-first | Show the result before explaining | Screen recording of the output |
| Permission | Tell them they can skip a step | "You do not need a developer for this" |

Record every real hook you analyse under its type in `research/hook-bank.md`.
